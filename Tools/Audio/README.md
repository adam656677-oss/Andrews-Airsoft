# Tools/Audio: synthesised sound for Andrew's Airsoft

Every sound effect, ambience and music loop in the game is generated by code.
There are no recorded samples. `make_sounds.py` (Python 3 + numpy) writes
**48 kHz / 16-bit PCM WAVs** to `Tools/Audio/Generated/<Key>.wav`. The Unreal editor
setup script (`Content/Python/airsoft_setup.py`) imports every `Generated/*.wav`
to `/Game/Airsoft/Audio/<Key>`. Gameplay code then loads them by key through
`AirsoftAssets::Sound(Key)` / `Play2D` / `Play3D`.

## Regenerate

```bash
python3 Tools/Audio/make_sounds.py                 # everything, writes Generated/ + _overview.png
python3 Tools/Audio/make_sounds.py --only FireRifle,SteelDing
python3 Tools/Audio/make_sounds.py --list          # keys, channels, loop flag, variation count
python3 Tools/Audio/make_sounds.py --jobs 1        # single process (default is 2 workers)
```

* **Requirements:** numpy. Optional: scipy (if importable, `scipy.signal.sosfilt` does the
  IIR filtering; otherwise filters run as exact frequency-domain IIR responses, which
  give the same output to ~1e-11). Pillow is used for the `_overview.png` contact sheet.
* **Deterministic:** every key/variation seeds its own RNG from `crc32("<Key>#<var>")`.
  Re-running reproduces the same files, and rebuilding one key never changes another.
* **Re-runnable:** files are overwritten in place. A full run also deletes stale
  `*.wav` files that no longer belong to any key.
* **Run time:** about 4-5 minutes for the full set on this machine with 2 workers. The two
  music loops take most of it. One-shots take well under a second each.
* At the end the script prints a check table for every file: peak, true peak, RMS,
  loudest 50 ms RMS, onset time, spectral centroid, clipped-sample count, and the loop seam
  metric. It also writes `Generated/_overview.png`, a waveform + log-frequency spectrogram
  contact sheet of every one-shot and loop.

## Output conventions

| | |
|---|---|
| Format | 48 kHz, 16-bit PCM WAV, TPDF-dithered |
| Channels | **mono** for positional (3D) one-shots; **stereo** for 2D UI / feedback / stingers, ambience and music |
| Level | normalised to **-1 dBTP** (4x-oversampled true peak), so nothing clips |
| One-shots | 20 Hz DC/rumble high-pass, leading silence trimmed to the transient, trailing silence trimmed below -62 dB, 5 ms raised-cosine fade-out |
| Loops | seamless by construction (see below); circular 20 Hz high-pass, zero DC |
| Variations | `<Key>_01.wav`, `<Key>_02.wav`, ... **plus** `<Key>.wav` (a copy of `_01`), so the plain key always exists |

### Loops

The six loops are marked **LOOP** in the tables below. Set `Looping` on the
imported SoundWave, or loop them in a MetaSound / Audio Component.

* **Ambiences** are synthesised circularly. Noise beds are coloured in the FFT
  domain, so they are periodic. Slow gust/swell modulators come from periodic random
  spectra. Filters and reverbs run as circular convolutions. Any event (bird call,
  car pass, distant burst) that runs past the end wraps around to the start. The loop
  point is therefore mathematically continuous, with no crossfade dip.
* **Music** is rendered once with all reverb and delay tails, then everything past
  the loop end is overlap-added back onto the start (`dsp.fold_tail`, the
  standard "wrap the tail" crossfade). The menu drone is synthesised circularly
  with loop-periodic frequencies.
* The check table's `seam` column is |last sample - first sample| divided by the
  file's 99.9th-percentile sample-to-sample step. Values below 1 mean the seam is an
  ordinary step. All loops measure 0.00-0.42.

## How Unreal imports them

`Content/Python/airsoft_setup.py` (the editor setup script) imports every
`Tools/Audio/Generated/*.wav` as a SoundWave named after the file, under
`/Game/Airsoft/Audio/<Key>`. That content folder is git-ignored and regenerated.
Code resolves `/Game/Airsoft/Audio/<Key>.<Key>`:

* `AirsoftAssets::Play3D(this, "FireRifle", Location, ...)` is positional, with the
  project's airsoft attenuation. Use the mono files.
* `AirsoftAssets::Play2D(this, "UIClick", ...)` is non-spatial. Use the stereo files.

Notes for the import script / audio setup:

* Keys flagged **LOOP** are imported with `looping = True`. `airsoft_setup_lib/importers.py`
  does this via `LOOPING_KEYS`, plus any key starting with `Ambience` or ending in `Music`,
  so new loops named that way loop automatically. Run the setup script with
  `--skip-audio` to leave audio alone. `_overview.png` is not imported (only `*.wav` is).
* Code currently plays the plain `<Key>`. That is the first variation, and it already
  gets per-shot pitch randomisation in code. To use every variation, wrap
  `<Key>_01..N` in a SoundCue Random node, or pick `"%s_%02d"` at random in code.
* Suggested starting volumes. The loops are peak-normalised like everything else, but their
  average loudness differs: AmbienceField / Street / Interior / Staging RMS is about
  -17 (Interior, dense crowd) to -25 (Staging) dBFS (use about 0.6-1.0). ClubMusic sits at about -13.6 dBFS RMS (use about
  0.3-0.45 under gameplay). MenuMusic is about -21.4 dBFS RMS (about 0.7).

## How the recipes work

Airsoft guns do **not** go bang. Each gun recipe layers the real mechanical events,
lets them glue through a little oversampled tanh saturation, and adds a short
synthesised outdoor tail (ground bounce, treeline slap echoes, diffuse decay with the
lows kept out so shots stay snappy):

* **AEG** (Rifle / SMG / DMR / LMG / Suppressed): piston slap into the cylinder head
  (gearbox shell + receiver modes excited by a strike click), piston mass thump,
  hollow receiver ring, air puff out of the barrel, a sub-millisecond BB/air snap, and
  the gearbox motor whir (rotation buzz + gear-mesh whine + brush noise) with spin-up,
  coast-down and anti-reversal-latch ticks. DMR adds a steel-piston clank. LMG adds
  box-mag BB rattle and the sound-activated winding buzz. The suppressed variant swaps
  the muzzle snap for a muffled "thup" plus suppressor-tube ring, so the mechanism is
  what you mostly hear.
* **Gas blowback** (Pistol / Magnum): sharp pneumatic crack + gas jet, hammer/valve
  tick, then two slide clacks (rearward stop, return to battery) with a slide-mass
  thump. Magnum: lower crack, more gas, heavier modes, slower slide.
* **Shotgun**: low gas/spring "whump" + three slightly offset BB air-hiss bursts +
  receiver clack.
* **Sniper (spring bolt)**: heavy piston thunk, metal cylinder ring and the
  dispersive chirp-train "twang" of the mainspring, with a muted muzzle (the game's
  sniper is flagged quiet / built-in suppressor).

Other building blocks (`airsoft_audio/`):

| module | contents |
|---|---|
| `dsp.py` | filters (RBJ biquads; scipy or exact FFT-domain IIR), STFT time-varying filter / spectral shaper, polyBLEP oscillators, modal resonators, envelopes, coloured & periodic noise, synthesised impulse responses (exponentially decaying noise with frequency-dependent decay + early reflections) and FFT convolution, oversampled saturation, true-peak, finishing, WAV I/O |
| `weapons.py` | gunfire recipes |
| `foley.py` | handling, impacts, steel, grenade, footsteps, landing |
| `feedback.py` | hit call, tagged, UI, chimes and stingers |
| `instruments.py` | brass, bell, piano, pluck, pad, kick/hat/clap, cinematic hit, reverse swell, riser |
| `ambience.py` | the four ambience loops (incl. a crude formant-voice crowd generator) |
| `music.py` | ClubMusic and MenuMusic |
| `report.py` | check table and contact sheet |

### Adding or changing a sound

Add an entry to the `RECIPES` dict of the relevant module:
`"Key": (fn, variations, "description"[, {"ch": 2, "loop": True}])`. Here `fn(rng, var)`
returns a float array: `(n,)` for mono, `(2, n)` for stereo. The driver handles seeding,
finishing (trim / fade / normalise or loop high-pass), writing the variation files,
the check table and the contact sheet. Run with `--only Key` while iterating.

## Size

The full set is **80 files, about 93 MB**. Almost all of it is the six stereo loops:
4 x 60 s ambience (about 46 MB), ClubMusic 64 bars @ 122 BPM = 125.9 s (about 24 MB), MenuMusic
90 s (about 17 MB). 48 kHz / 16-bit stereo is 11.5 MB per minute, and the loops total 7.6
minutes (87.5 MB). The 74 one-shot files are 5.5 MB. That is over the ~60 MB target. The stated loop
lengths and format were kept, and only the length budget changes the size.
Ways to get under 60 MB if that matters: shorten the ambiences to 30-40 s, write the
ambiences at 32 kHz, or keep `Generated/` out of git and regenerate it, as is already done
for `SourceAssets/` and `Content/Airsoft/Audio/`. Unreal compresses on import either way,
so the shipped size is much smaller.
