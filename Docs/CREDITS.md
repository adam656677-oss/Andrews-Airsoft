# Credits

Third-party assets used by Andrew's Airsoft. Everything else (models, procedural textures, audio, code)
is made for the project.

## Textures

The tables below are regenerated by `python3 -I Tools/Textures/fetch_cc0.py` (asset ids, resolutions and
the conversion steps live in its `TABLE`). Re-running it downloads the same assets again, re-checks
each licence on the asset's page, and rewrites `SourceAssets/Materials/<Material>/` and
`Content/Airsoft/Data/Materials.json`.

Materials still procedural (`Tools/Blender/environment/materials.py`): MarbleBlack, Brass, Rubber,
Netting, Straw, Granite, PlywoodPainted, PaintLineWhite, PaintLineYellow.

## Voice

The story voice-over (`Tools/Audio/Generated/Voice/VO_*.wav`) is synthesised by
`Tools/Audio/make_voice_neural.py` with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)
(hexgrad, [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0), commercial use permitted).
The voices are Kokoro's own synthetic voices (some blended); none imitates a real person.
Pronunciation uses [misaki](https://github.com/hexgrad/misaki) (Apache-2.0) and spaCy `en_core_web_sm` (MIT).
