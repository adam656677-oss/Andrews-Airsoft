# Credits

Everything that ships with Andrew's Airsoft: *Last Contract*, and where it came from. The short version:
the game's models, levels, sounds, music, code and story are made for the project; the engine, the base
character body, the scanned surfaces, the voice model and the fonts come from the sources below, each
under a licence that allows use in the game.

The in-game credits roll (`Credits` in `Content/Airsoft/Data/Campaign.json`) is the short form of this page.

## Made for this project

| What | Where it comes from |
|---|---|
| Story, characters, mission scripts | Written for the game (`Content/Airsoft/Data/Campaign.json`, `Docs/Last_Contract_Voice_Script.html`) |
| Gameplay code, UI, AI | C++ in `Source/AndrewsAirsoft` |
| Guns, attachments, props, cars, gear, suits, levels | Generated by the Blender Python scripts in `Tools/Blender` (the AVERNE cars, their marque and every sign, plate and brand in the levels are invented) |
| Level layout and editor setup | `Content/Python/airsoft_setup_lib` |
| Procedural materials | `Tools/Blender/environment/materials.py` (the ones not replaced by scans, listed below) |
| Gun sounds, foley, ambience, music, UI sounds | Synthesised by `Tools/Audio/airsoft_audio` |
| HUD mock-ups, trailer and press stills | `Tools/HUD/hud_mockup.py`, `Docs/Trailer/build_trailer.py` |

No real people, brands or places are depicted. Characters are faceless mannequins in original clothing.

## Engine and Epic Games content

- **Unreal Engine 5** by Epic Games, used under the [Unreal Engine EULA](https://www.unrealengine.com/eula).
  A released build owes Epic a royalty only above the EULA's revenue threshold; a free game shared with
  friends owes nothing, but the EULA still applies to any distribution.
- **UE5 Mannequin "Manny"** (`/Game/Characters/Mannequins`, `SKM_Manny_Simple`, `ABP_Unarmed`) from the
  Third Person template / feature pack. Epic content licensed for use in Unreal Engine projects only.
- **Engine font Roboto** (`FCoreStyle` and `RobotoDistanceField`), shipped with the engine
  (Apache License 2.0).

## Textures

The tables below are regenerated by `python3 -I Tools/Textures/fetch_cc0.py` (asset ids, resolutions and
the conversion steps live in its `TABLE`). Re-running it downloads the same assets again, re-checks
each licence on the asset's page, and rewrites `SourceAssets/Materials/<Material>/` and
`Content/Airsoft/Data/Materials.json`.

Materials still procedural (`Tools/Blender/environment/materials.py`): MarbleBlack, Brass, Rubber,
Netting, Straw, Granite, PlywoodPainted, PaintLineWhite, PaintLineYellow.

## Voice

The story voice-over (`Tools/Audio/Generated/Voice/VO_*.wav`) is synthesised by
`Tools/Audio/make_voice_neural.py` with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M)
(hexgrad, [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0), commercial use permitted).
The voices are Kokoro's own synthetic voices (some blended); none imitates a real person.
Pronunciation uses [misaki](https://github.com/hexgrad/misaki) (Apache-2.0) and spaCy `en_core_web_sm` (MIT).
Line checks during development used [Whisper](https://github.com/openai/whisper) `openai/whisper-base.en`
(OpenAI, MIT) to transcribe the generated lines. It is a development tool only; nothing from it ships.
