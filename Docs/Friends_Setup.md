# Andrew's Airsoft: install and play

This page is for players. You don't need Unreal Engine or anything else from the developer side.

## What you need

- A Windows 10 or 11 PC with a graphics card about as fast as an RTX 2060 or better.
- Free disk space of about twice the size of the zip, for the zip plus the extracted game.

## Install (once per new build)

1. Download the zip, for example `AndrewsAirsoft_v1.0.zip`.
2. Right-click it, choose **Extract All**, and pick a folder such as `C:\Games\AndrewsAirsoft`.
3. Run `AndrewsAirsoft.exe`. If Windows SmartScreen appears, click **More info → Run anyway**.

When a new build comes out, delete the old folder and extract the new zip. Your story progress, rank and settings are kept, because they're stored separately in `%LOCALAPPDATA%\AndrewsAirsoft`.

## Play

- **Continue** picks the story up at your last checkpoint.
- **New Game** starts the story, *Last Contract*, at the difficulty you choose.
- **Mission Select** replays any mission you've unlocked.
- **Skirmish** is a quick match against bots on any map.
- **Practice Range** walks you through the controls.

## Controls you need first

| Action | Keyboard / mouse |
|---|---|
| Move / look | WASD / mouse |
| Fire / aim | Left / right mouse |
| Sprint / crouch / slide | Shift / C (C while sprinting slides) |
| Reload / grenade | R / G |
| Melee strike | Z or Mouse 4 |
| Lean | Q / E |
| Loadout | L |
| First or third person | F5 |
| Pause | Esc |

A controller works too. Every control is listed in **Settings**.

## Settings for smooth play

Open **Settings → Graphics**. On an RTX 2060 or 2070, use *Quality: High* and *Render scale: 60%*. If it stutters, drop to 50%.

## If something goes wrong

| Problem | Fix |
|---|---|
| The game won't start | Install the latest graphics driver, then try again. |
| Very low frame rate | Lower Render scale in Settings, and close browsers or recording apps. |
| The game crashes | Send the developer the newest folder inside `%LOCALAPPDATA%\AndrewsAirsoft\Saved\Crashes`. |
